# FutureReady AI 🚀

## AI-Powered Student Skill Gap Analysis and
## Personalized Career Development System

FutureReady AI is a full-stack web application that
helps students evaluate their current skills, explore
career matches, identify skill gaps, and follow a
personalized learning roadmap.

## Features

- Career match percentage
- Student skill management
- Skill gap analysis
- Personalized learning roadmap
- Skill progress tracking and visualization
- Rule-based career advice
- Interactive React dashboard

## Technology Stack

- Frontend: React, Vite, CSS
- Backend: Java, Spring Boot
- Database: MySQL
- API Communication: Axios
- Data Access: Spring Data JPA
- Charts: Recharts

## Project Structure

- frontend/ — React application
- backend/backend/ — Spring Boot application

## How It Works

1. Students review their current skill levels.
2. The application compares skills with career requirements.
3. Students identify areas that need improvement.
4. The application provides learning recommendations.
5. Students update their skills and track progress.

## Current Implementation

The career advisor uses predefined rules and templates.
A live generative-AI API is not integrated in this version.
